# SchHub

SchHub is a secure, user-friendly web experience for signing in, creating an account, and accessing a personal dashboard. The application supports modern sign-in options, including biometric authentication on supported devices, while preserving a standard fallback sign-in flow.

## Security note

This project is intended for approved users and should be used in line with your organization’s security and privacy requirements. Please do not share sensitive account details or authentication information outside the official application flow.
